# mercilint 🔥

Brutal code roasts where every insult comes with a fix.

A Claude Code skill that reviews your working diff with zero mercy — but every roast maps to a concrete, severity-ranked fix. Funny on the surface, rigorous underneath.

## Install

```bash
git clone https://github.com/kpab/mercilint ~/.claude/skills/mercilint
```

## Usage

```
/roast
```

Roasts your uncommitted changes. Every burn comes with a severity (critical / high / medium / low) and a concrete fix.
