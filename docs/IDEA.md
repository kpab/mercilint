# アイデア: mercilint

## コンセプト
コードを容赦なく煽る(roast)が、全ツッコミが実際の修正提案に対応しているClaude Codeレビュースキル。「ネタの皮を被った実用スキル」。

## 背景・動機
- 壁打ちで「少ない工数で確実に伸ばせる」「グローバル向け(日本市場は狙わない)」が条件に
- 英語圏スキル市場の勝ちパターンは「1つの仕事に特化＋方法論を蒸留」型(power-design 504★、tufte-claude-skill 277★等が数週間で数百★を再現)
- 純ネタ枠はcaveman(87k★)が宝くじを当てた後でクローンは伸びない → ネタ×実用の重ね掛けで狙う
- スキルはMarkdownのみで完結し、ビルド・デプロイ・運用が不要(工数最小)

## ラフスコープ
- やる:
  - 毒舌だが的確なコードレビューを行うスキル本体(SKILL.md)
  - 全roastが検証可能な修正提案にマッピングされる仕組み(severity付き)
  - 映えるREADME(デモ例、before/after)
  - 英語でのグローバル公開(GitHub: kpab)
- やらない(今回は):
  - CLI・VSCode拡張などのコード実装
  - 日本語ローカライズ
  - Web UI・SaaS化

## 競合・差別化(2026-07-10調査)
判定: **競合あり・差別化可能**。code-roast系は小粒実装が多数あるが全て11★以下で伸びたものはゼロ(最大 humairshoukat/AI-Code-Roast 11★)。2026-07-09にも中国語圏でClaude Code roastスキル(2★)が出たばかりで、思いつく人は多いが誰も作り込んでいない。差別化は「方法論の蒸留＋roast→修正の完全マッピング＋映えるREADME」の実行品質。勝敗は実行品質と初動の見せ方で決まる。

## 検討した他の候補
- 方言・キャラ系スキル(博多弁ギャル公開版): 日本市場を狙わない方針のため見送り
- コミットたまごっち(Go製TUIペット): 工数1〜2週間とやや重く「確実に伸ばす」に不安
- AIエージェント観戦アリーナ: 工数大、スペクタクル頼み
- Daily系開発者ミニゲーム(Cloudflare): 毎日のコンテンツ供給が必要で運用が重い
- 実用特化型スキル(Goレビュー方法論等): 確実性は最高だが面白み不足で本人の熱量が乗らない
- 並列セッション運用ツール/ガードレール/コスト可視化: 実用系トレンド枠、面白系方針への転換で見送り
